# Hi, I’m OllaAmigos 👋

**Machine Learning · Model Evaluation · Applied Research**

I work on evaluating machine learning systems, translating model behavior into measurable quality signals, and turning research findings into product decisions.

My interests span **generative AI evaluation, experimental design, error analysis, causal inference, and applied machine learning**. I enjoy building evaluation frameworks that are transparent, reproducible, and useful for real-world decisions.
